# Bufferly

Bufferly is a local-first clipboard workspace for developers and AI-heavy workflows.

It is a native macOS app focused on fast clipboard recall, pinned reusable snippets, content type recognition, and sensitive content filtering.

## Stack

- Swift
- SwiftUI
- AppKit
- SQLite, planned for local persistence
- Keychain, planned for sensitive configuration

## Run

```bash
swift run Bufferly
```

## Build

```bash
swift build
```
